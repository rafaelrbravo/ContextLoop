ChatGPT Prompt Launcher

Prompt buttons appear in a compact bar at the top of ChatGPT's left sidebar. Click normally to launch in the current tab; Ctrl-click or middle-click uses the browser's normal new-tab behavior.

Each prompt has its own color. The slider changes HSV hue. Launched ChatGPT tabs use that color: faded while working, full color when stopped or awaiting attention. Circle = Chat; square = Work.

Transfer prompts between installed versions. Copies names, text, colors, and order only; no bookmarks.

Bookmarks are added at the far left of the bookmarks bar and use the prompt color. Existing Prompt Launcher bookmarks update automatically when you rename a prompt or change its color.
